# qq-companion-deepseek

一个住在你电脑里、用 QQ 小号跟你聊天的 AI 伙伴：有记性、有情绪、熟了会贫、会主动找你，没人理它的时候会自己找事做。
大脑是 DeepSeek（通过 DSH），QQ 这头用 NapCat。只支持 Windows。

## 下载安装

1. 点这个页面上绿色的 **Code → Download ZIP**，下载后解压。
2. 双击 **安装.cmd**（会弹一次管理员确认），按提示填：给它起的名字、机器人的 QQ 号、你的 QQ 号、DeepSeek API Key。
3. 勾要哪些功能，点开始安装。安装器会在线下载 Node.js、DSH、NapCat，一共几百 MB。
4. 桌面上会多一个快捷方式，双击启动，第一次用手机 QQ 登录**机器人那个号**扫码。

装之前要准备：

- Windows 10 / 11，能上网
- 电脑版 QQ（[im.qq.com](https://im.qq.com) 下载）
- 一个给机器人用的 QQ 小号
- 一个 DeepSeek API Key（[platform.deepseek.com](https://platform.deepseek.com) → API Keys，充一点钱）

能勾哪些功能、怎么改人设和设置、QQ 里能用的命令，都在 [使用说明](使用说明.md)。

## 它会什么

- **像人一样聊天**：连发几条会等你说完再回，按字数“打字”，偶尔手滑打错字，群里被叫到才说话
- **记性和日记**：记住聊过的事，每天睡前写日记当长期记忆，过两天会自然地问一句后来怎么样了
- **心情和作息**：心情跟着发生的事走、会延续几个小时；记得你平时几点睡几点起
- **主动找你、自己找事做**：早安晚安、好久没聊冒个泡；没人理它时刷 B站、看番、刷热榜、听歌，慢慢长出自己的喜好
- **表情包、学说话**：会发表情图、收你发的表情包；把一段聊天记录合并转发给它，它会慢慢学那个人的说话方式
- **发语音**（阿里云百炼 CosyVoice）：语音能带生气、委屈、害怕、困这些语气
- **深夜电台**：说“开台，今晚想听点适合下雨的”，它录一期两三分钟的语音节目，配节目卡、推荐一首歌
- **可选**：手机控制（adb）、听声音 / 看直播（本地 Whisper）、唱歌（要另外装 Seed-VC，安装包不带任何人的声音模型）

## 注意

- NapCat 是第三方 QQ 协议端，不是腾讯官方的机器人接口。用小号，别群发、别刷屏，主号有被冻结的风险。
- 聊天记录、记住的事、日记都只存在本机的 `agent-bridge\data\` 里；API Key 存在 `agent-bridge\.env`，别发给别人。
- 只把信得过的 QQ 号加进白名单：刷 B站、手机控制、听声音这些功能会让它在你电脑上执行命令。
- 发语音、唱歌只用你自己的声音，或者本人同意的声音。
