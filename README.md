# qq-companion-deepseek

最近 B 站刮起一阵“养鱼”风，把 DeepSeek 接进 QQ，养一个会聊天的 AI。教程一搜一大把：装 NapCat、接 DeepSeek、调人设、配语音……一步步跟下来要折腾好半天，能一键装好的整合包却不多见。所以做了这个：双击安装，勾上想要的功能就能用。

装好后是一个用 QQ 小号陪你聊天的 AI 伙伴：有记性、有情绪、熟了会贫、会主动找你，没人理它的时候会自己找事做。
大脑是 DeepSeek（通过 DSH），QQ 这头用 NapCat。只支持 Windows。

## 下载

- **离线安装包（推荐）**：在 [Releases](https://github.com/yzs6615/qq-companion-deepseek/releases/latest) 里下 `qq-companion-deepseek-offline-*.zip`（约 230MB）。自带 Node.js 24 和 DSH，装的时候不用再下它们，装好约 1.2GB。
- **在线安装包**：点这个页面上绿色的 **Code → Download ZIP**（几百 KB）。装的时候会在线下载 Node.js 和 DSH，一共几百 MB。

## 安装

1. 解压，双击 **安装.cmd**（会弹一次管理员确认），按提示填：给它起的名字、机器人的 QQ 号、你的 QQ 号、DeepSeek API Key。
2. 勾要哪些功能，点开始安装。
3. 装到 NapCat 那一步，会自动打开浏览器下载 `NapCat.Shell.Windows.Node.zip`（约 120MB）。NapCat 不让别的软件转发，所以要从它的官网下。下好放在“下载”文件夹就行，安装器会自己找到、接着装好；GitHub 下不动就点安装窗口里的“国内加速链接”。
4. 桌面上会多一个快捷方式，双击启动，第一次用手机 QQ 登录**机器人那个号**扫码。

装之前要准备：

- Windows 10 / 11，能上网
- 电脑版 QQ（[im.qq.com](https://im.qq.com) 下载）
- 一个给机器人用的 QQ 小号
- 一个 DeepSeek API Key（[platform.deepseek.com](https://platform.deepseek.com) → API Keys，充一点钱）

能勾哪些功能、怎么改人设和设置、QQ 里能用的命令，都在 [使用说明](使用说明.md)。

## 它会什么

- **像人一样聊天**：连发几条会等你说完再回，按字数“打字”，偶尔手滑打错字，群里被叫到才说话
- **直接跟她说就行**：“半小时后提醒我喝水”“我在杭州”“给我写封信”“别放了 小声点”“给我画只猫”，不用记命令；发 QQ 语音她也听得懂（本地 Whisper）
- **记性和日记**：记住聊过的事，每天睡前写日记当长期记忆，过两天会自然地问一句后来怎么样了
- **心情和作息**：心情跟着发生的事走、会延续几个小时；记得你平时几点睡几点起
- **主动找你、自己找事做**：早安晚安、好久没聊冒个泡；没人理它时刷 B站、看番、刷热榜、听歌，慢慢长出自己的喜好
- **表情包、学说话**：会发表情图、收你发的表情包；把一段聊天记录合并转发给它，它会慢慢学那个人的说话方式
- **发语音**（阿里云百炼 CosyVoice）：语音能带生气、委屈、害怕、困这些语气
- **深夜电台**：说“开台，今晚想听点适合下雨的”，它录一期两三分钟的语音节目，配节目卡、推荐一首歌
- **可选**：手机控制（adb）、听声音 / 看直播（本地 Whisper）、唱歌（要另外装 Seed-VC，安装包不带任何人的声音模型）
- **心情头像**（默认关）：她心情变了 QQ 头像跟着换，图自己准备，见 [使用说明](使用说明.md)
- **更多“像人”的小功能**（默认关）：电脑室友（看得见你在放的歌、开着的游戏，像室友一样顺口吐槽）、做梦、问她在干嘛回一张现场照、每周日晚上给你写一封信、用 QQ 音乐放歌、旅行明信片、QQ 空间说说，见 [使用说明](使用说明.md)
- **她自己的小屋**（ChronoLife，默认关）：没人找她时她也在过日子，养植物、整理笔记、写点东西，聊天时记得；可以让她有了具体的事偶尔主动说一句（一周最多 3 条），见 `agent-bridge\packages\life\chronolife\README.md`

## 注意

- NapCat 是第三方 QQ 协议端，不是腾讯官方的机器人接口。用小号，别群发、别刷屏，主号有被冻结的风险。
- 聊天记录、记住的事、日记都只存在本机的 `agent-bridge\data\` 里；API Key 存在 `agent-bridge\.env`，别发给别人。
- 只把信得过的 QQ 号加进白名单：刷 B站、手机控制、听声音这些功能会让它在你电脑上执行命令。只有主人私聊时她才能动电脑和手机，别人私聊、群里都是只读；手机上不打电话、不替你发消息、不付款。
- 发语音、唱歌只用你自己的声音，或者本人同意的声音。
- 离线包里自带的 Node.js 是 MIT 许可证，全文在 `tools\node\LICENSE`；DSH（MIT）和它的依赖各自的许可证在 `agent-bridge\node_modules` 里。
