# QQ 机器人 · 使用说明

一个住在你电脑里、用 QQ 小号跟你聊天的家伙：有记性、有情绪、熟了会贫、会主动找你。
大脑是 DeepSeek（通过 DSH），QQ 这头用 NapCat。

## 装之前

- Windows 10 / 11，能上网。
- **装好电脑版 QQ**（im.qq.com 下载）。安装器会自己找到它。
- 一个 **QQ 小号** 给机器人用。NapCat 是第三方协议端，不是腾讯官方机器人，主号有被冻结的风险；别群发、别刷屏。
- 一个 **DeepSeek API Key**：platform.deepseek.com → API Keys，充一点钱。

## 安装

1. 解压，双击 **安装.cmd**（会弹一次管理员确认）。
2. 选安装位置；在国内就勾“用国内镜像”。
3. 填名字、机器人的 QQ 号、你的 QQ 号、DeepSeek API Key。
4. 勾要哪些本事（下面有说明），点开始安装。**离线包**自带 Node.js 和 DSH，不用再下；在线包要下载几百 MB。
5. 装到 NapCat 那一步，会自动打开浏览器下载 `NapCat.Shell.Windows.Node.zip`（约 120MB）。NapCat 不让别的软件转发，所以要从它的官网下。下好放在“下载”文件夹就行，安装器会自己找到、接着装；GitHub 下不动就点安装窗口里的“国内加速链接”。
6. 桌面会多两个快捷方式：
   - **「名字」**：启动。第一次会显示二维码，用手机 QQ 登录**机器人那个号**扫码。
   - **「名字」状态**：看它在不在线、有没有报错（不显示聊天内容）。

## 可以勾的本事

| 本事 | 说明 | 额外下载 |
|---|---|---|
| 心情和作息 | 心情跟着发生的事走、会延续几个小时；记得你平时几点睡几点起，晚睡早起她会注意到；对你还不了解的地方会找机会问 | — |
| 记性、日记和回访 | 记住聊过的事；每天睡前写日记，当长期记忆（跟谁聊的只给谁看），启动器上点“日记”能按日期翻；过两天自然地问一句；学你的口头禅 | — |
| 主动找你 | 早安晚安、好久没聊冒个泡；她问了你一句你半天没回会追一句“人呢”；偶尔戳你一下；被冷落了有点小情绪 | — |
| 自己找事做 | 没人理它时自己找点事干（刷 B站、看番、刷知乎热榜、刷微博热搜、听歌，轮着来），睡前回想，慢慢长出自己的喜好 | — |
| 表情包 | 会发表情图，会收你发的表情包 | 约 2MB |
| 学某个人说话 | 把一段聊天记录合并转发给它，回序号选人，它慢慢学那个人的说话方式 | — |
| 刷 B站 | 自己刷热门、看视频的弹幕热评和画面 | Python 库 |
| 手机控制 | USB 调试控制安卓手机 | adb 约 10MB |
| 听声音 / 看直播 | 本地 Whisper 把声音转文字；你发的 QQ 语音她也能听懂（只用本机模型，没装就让你打字） | 约 450MB |
| 发语音 | 阿里云百炼 CosyVoice：填百炼 API Key 和复刻的音色 ID；语音会带语气（生气、委屈、害怕、困…），跟着她的心情走 | — |
| 唱歌 | 发提前转好的歌，见下面“唱歌” | 另装 Seed-VC |
| 深夜电台 | 说“开台，今晚想听点适合下雨的”，她录一期两三分钟的语音节目，配节目卡、推荐一首歌；能投稿让她念、能接着上期聊、能只听一分钟 | 没开发语音就发文字版 |

**刷 B站 / 手机 / 听声音** 需要让它能在电脑上执行命令（安装器会自动打开）。只把信得过的 QQ 号加进白名单。

**谁能让她动手**：主人（安装时填的“你的 QQ”，也就是 `.env` 里 `PROACTIVE_QQ` 第一个；填了 `PC_OWNER` 就按它）私聊时，她能用电脑上的工具（刷 B站、手机、截图、放歌、发图、画画这些）。别人私聊、群里（主人在群里也一样）她只陪着聊天、只能看不能动，让她弄手机、电脑上的文件、放歌，她会直接说不行。

## 改设置

- **人设**：`agent-bridge\persona.md`，就是一篇写给它的说明，随便改。改完在启动器里选“只重启 bridge”。
- **换功能 / 换 key / 加人**：再运行一次 `agent-bridge\installer\修改设置.cmd`（或者重新运行安装包、选同一个目录）。key 不重填就沿用原来的。
- 其他细项（多久主动找一次、一天最多发几条语音……）在 `agent-bridge\.env`，改完重启 bridge。
- 启动器右上角“功能与机制”能看到现在开了什么、它长成了什么样。

## 直接跟她说就行

不用记命令，像跟人说话一样说就行，比如：

- “半小时后提醒我喝水”“明早 8 点叫我起床”“我有哪些提醒”（没说多久她会先问你；“每天提醒我”这种重复的还不支持，她会先设最近的一次）
- “我在杭州”（以后知道你那边的天气）·“我生日 5 月 20 号”
- “给我看看你的日记”
- “唱首歌”“唱那首里‘某一句’那段”“你会唱啥”（得先教会她，见下面的“唱歌”）·“用语音说句晚安”·“用电脑喇叭跟我说句晚安”（开了电脑喇叭才有，只听主人的；喊不了时她会直接说为啥）
- 直接发 QQ 语音给她（用本机的 Whisper 听，没装或者没听清她会让你打字）
- “放首歌”“别放了”“小声点”“切一首”“上一首”（开了用 QQ 音乐放歌才有，只听主人私聊的，按的是电脑上的媒体键）
- “截个图给我看看”（主人私聊：她截了手机或者屏幕的图会直接发过来，只发她自己截的、拍的、画的图）
- “给我画只猫”（主人私聊、填了百炼 key 才有：用通义万相画一张发过来，一张一两毛，一天最多 3 张，`DRAW_MAX_DAY` 可改，`DRAW=false` 关掉）
- “开台，聊聊下雨天”（深夜电台）
- “给我写封信”（开了每周一封信才有）·“给我寄张明信片”（开了旅行明信片才有）·“发条说说”（开了 QQ 空间说说才有，只听主人的）
- 学说话：把聊天记录合并转发给她，再说“学第二个人”“学小明”；不想要了说“别学了”
- 开了她自己的小屋：“帮我记着下周三考试”“那条记错了 是周四”“那个别记了”；主人私聊还能说“这几天别主动找我”“可以主动找我了”

写信、寄明信片、发说说只在私聊里办。办不成的（时间没听懂、今天放够了、照片没拼好……）她会跟你说一声。改 QQ 昵称、签名、头像她不会自己动，要改你自己改。发 `/help` 能看到这些例子。

排错用的命令还在：`/status` 状态 · `/心情` · `/new` 开新对话。以前的 `/提醒 30m 喝水` `/城市 杭州` `/生日 5-20` `/日记` `/学说话` `/别学了` `/说话 你好` `/唱歌 歌名` `/歌单` `/电台 帮助` `/信` `/明信片` `/说说` `/生活 帮助` 也照样能用。

## 唱歌（进阶）

安装包不带任何人的声音模型。想让它唱歌：

1. 自己装好 [Seed-VC](https://github.com/Plachta/seed-vc)（要 NVIDIA 显卡），在 `agent-bridge\.env` 里填 `SEEDVC_RUNTIME`（Seed-VC 代码目录）和 `SEEDVC_PY`（它的 python）。
2. 只用**本人同意**的声音。最好先用这个声音（最好有清唱）微调一下唱歌模型，放到 `agent-bridge\data\sing-model\ft_model.pth`，再放一段 20 秒左右的清唱当参考：`agent-bridge\data\sing-model\ref_sing.wav`。
3. 转歌：`node agent-bridge\sing\learn.mjs start --title 歌名 --artist 歌手 --audio 歌.flac --seg 46.5-85`（也可以 `--bv BV号` 直接用 B站 的音轨）。一段 30 秒要 5 分钟左右，在后台转，`node agent-bridge\sing\learn.mjs status 歌名` 看转到哪了。转好的放进歌库，它就会唱了。在 QQ 里让她“学首歌”，她自己也是这么转的。

## 心情头像（可选，默认关）

她心情变了，QQ 头像跟着换，半夜换成睡觉的那张。

1. 自己准备几张正方形的图，按心情起名放进 `agent-bridge\data\avatars\`：`平常.png`、`开心.png`、`生气.png`、`委屈.png`、`困.png`、`睡觉.png`（还可以有 `得意`、`烦`、`无聊`、`懒`）。至少要有 `平常`，缺的会用相近的代替。
2. 在 `agent-bridge\.env` 里加一行 `MOOD_AVATAR=true`，重启 bridge。开了以后它原来的头像会被换掉。
3. 一天最多换 4 次、两次至少隔 90 分钟（`.env` 里的 `MOOD_AVATAR_MAX_DAY`、`MOOD_AVATAR_GAP_MIN` 可以改），换太勤小号容易被风控。

## 更多“像人”的小功能（可选，默认关）

都在 `agent-bridge\.env` 里打开，改完重启 bridge：

- **电脑室友**（`PC_BUDDY=true`）：她“住在这台电脑里”，看得见电脑上在放什么歌（网易云、QQ音乐、酷狗、Spotify……）、开着什么游戏、电脑开了多久、半夜人还在不在电脑前。聊天时心里有数；一首歌这周放到第 3 遍、凌晨还在打游戏、电脑连开好几天，会像室友一样顺口说一句（一天最多 3 句）。只看这几样，别的窗口一概不看；只在私聊里跟 `PROACTIVE_QQ` 第一个人（电脑的主人）提。
- **做梦**（`DREAM=true`）：早上醒来有时记得昨晚的梦，是拿最近的事拼的；当天第一次聊天、或者发早安时可能顺口说一句。
- **现场照**（`PHOTO=true`）：问她“在干嘛”，她可能回一张“现在的她”。图要自己准备：`agent-bridge\data\scene\bg\` 里放她房间的样子（`morning`、`day`、`evening`、`night`、`rain-day`、`rain-night`、`snow`，jpg 或 png，至少要有 `day`），`agent-bridge\data\scene\pose\` 里放透明底的人物动作（`look`、`happy`、`pout`、`sad`、`sleepy`、`sleeping`、`phone`、`radio`、`eat`……，至少要有 `look`）。一天最多 5 张。
- **每周一封信**（`LETTER=true`）：每周日晚上 9 点后给你写一封信，聊聊这一周。信纸用阿里云百炼的通义万相画（就是发语音用的那个 `DASHSCOPE_API_KEY`，一张一两毛钱；没有 key 就用素纸），字用电脑上的手写体排。私聊跟她说“给我写封信”就马上写一封。
- **自定义在线状态**（`DIY_STATUS=true`）：QQ 名字旁边的状态写她自己的一句话：在刷什么、“陪你听：歌名”、生气时“别惹我”；没具体的事就用预设的那几种。
- **作息被你带偏**（`SLEEP_DRIFT=true`）：你最近老熬夜，她也跟着晚睡（最多晚 2 小时），还会抱怨一句“都怪你”。
- **电脑喇叭说话**（`SPEAKER=true`，要开电脑室友和语音）：早上你第一次坐到电脑前、或者离开两个小时又回来，她用自己的声音从电脑喇叭说一句“早”“回来啦”。你私聊跟她说“用电脑喇叭跟我说句晚安”，她也会从喇叭说（只听电脑主人的，一天最多 10 句，`SPEAKER_ASK_MAX_DAY` 可改）。都是她自己的声音，不会用系统那种机器声；夜里（23 点到 9 点）不出声。
- **电脑上留便条**（`NOTES=true`，要开电脑室友）：你离开电脑好几个小时，她偶尔在桌面留一张便条，你回来时右下角弹个通知。
- **桌面抽屉**（`DRAWER=true`）：桌面上一个“她的抽屉”文件夹，她写的信、寄的明信片、发给你的照片、梦、便条都放一份。
- **用 QQ 音乐放歌**（`PLAY_MUSIC=true`）：让她“放首歌”，你在电脑前她就直接用电脑上的 QQ 音乐放，不在就发 QQ 音乐的链接。说“别放了”“接着放”“切一首”“上一首”“大声点”“小声点”，她按电脑上的媒体键（不用管理员，不关软件）。只听主人私聊的。
- **旅行明信片**（`POSTCARD=true`）：隔几周的周末她出去玩一趟（自己小世界里的），周日给你寄一张明信片，正面用百炼画当地风景（一张一两毛钱）。私聊跟她说“给我寄张明信片”就马上寄一张。
- **送她的东西摆进房间**（跟着 `PHOTO`）：说“送你个……”或者发张图，她收下后会把这个东西画出来摆进她的房间，拍一张给你看。
- **她自己的小屋**（`CHRONOLIFE=true`）：没人找她时她也在过日子：窗台上养着一盆植物、整理笔记、写点东西、发呆，自己找事做刷到的也算进去；聊天时记得这些事。再开 `CHRONOLIFE_PROACTIVE=true`，小屋里有了具体的事她会偶尔主动跟你说一句（一周最多 3 条，夜里不发，上一条你没回就不发下一条），原来那几种主动消息也交给它统一管。让她记事、改记错的、别主动找你，直接跟她说就行（`/生活 帮助` 也还能用），细节见 `agent-bridge\packages\life\chronolife\README.md`。
- **QQ 空间说说**（`QZONE=true`）：偶尔（大概两天一条）把自己最近干的事发一条说说，好友可见；不写聊天内容和别人的名字。主人私聊跟她说“发条说说”就马上发一条。

拿别人画的角色当图，同样先看清楚作者许不许。

## 卸载

关掉启动器，删掉安装目录和桌面上两个快捷方式。QQ、Python（还有在线包装的 Node.js）是单独装的，不想要就在“应用”里卸载；离线包自带的 Node.js 在安装目录里，跟着一起删掉了。

## 隐私

- 聊天记录、记住的事、学到的说话方式都只存在本机 `agent-bridge\data\` 里。
- `.env` 里有你的 key，别发给别人。
