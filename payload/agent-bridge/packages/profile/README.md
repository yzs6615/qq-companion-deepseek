# dsh-companion-profile（QQ 上的样子）

让她的 QQ 资料也“活”起来：点开她的资料就能看出她今天怎么样——在线状态跟着作息和心情变，
签名每晚换一句，心情变了换头像，偶尔还发条 QQ 空间说说。

## 她多了什么

- **在线状态**：睡觉时段“睡觉中”，23 点到 1 点“熬夜中”，自己找事做时“摸鱼中”，唱完歌“听歌中”，
  其他时候跟着心情（无聊中、元气满满、想静静、一言难尽、被掏空……）。只在变了的时候才去改。
- **自定义在线状态**（默认关）：名字旁边写她自己的一句话（在干嘛、陪你听什么、什么心情），没有具体的事就用预设的。
- **个性签名**：每晚写完日记顺手写一句换上（所有人都看得到，所以不带人名和私事）。
- **心情头像**（默认关）：心情变了换 QQ 头像。图你自己准备，放在 `data/avatars/`，按名字找：
  `平常`、`开心`、`无聊`、`懒`、`困`、`睡觉`、`得意`、`烦`、`生气`、`委屈`（png / jpg / jpeg / webp）。
  对应的那张没有就往后找，最后用 `平常`；一张都没有就不换。
- **QQ 空间说说**（默认关）：偶尔把自己最近干的事发一条（一天最多一条），只写她自己的事，不写聊天内容、人名和 QQ 号；
  开着现场照的话一半的时候配一张“现在的她”。主人私聊跟她说“发条说说”，她就马上发一条，发完告诉你发了啥；别人说了不算。

## 安装

先装本体（dsh-companion-core），再装这个：

```bash
dsh plugin --profile web add github:yzs6615/dsh-companion-plugins#profile
```

用桌面版把 `web` 换成 `desktop`（先完全退出桌面版）。也可以到
[Releases](https://github.com/yzs6615/dsh-companion-plugins/releases) 下载 `dsh-companion-profile-<版本>.tgz`，
`dsh plugin --profile web add <文件路径>`。装好、卸掉后重启 DSH。卸载：`dsh plugin --profile web remove dsh-companion-profile`。

## 设置（.env）

写在本体的 `.env` 里（默认 `$DSH_HOME/companion/.env`），改完重启 DSH。开关写 `true` / `false`，数字项别留空。

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `ONLINE_STATUS` | 开 | 在线状态跟着作息和心情变 |
| `DIY_STATUS` | 关 | 自定义在线状态 |
| `LONGNICK` | 开 | 每晚写完日记换个签名（要装“记得你”插件、开着日记） |
| `MOOD_AVATAR` | 关 | 心情头像 |
| `MOOD_AVATAR_DIR` | `data/avatars` | 头像图放哪 |
| `MOOD_AVATAR_MAX_DAY` | `4` | 一天最多换几次 |
| `MOOD_AVATAR_GAP_MIN` | `90` | 两次之间至少隔几分钟 |
| `QZONE` | 关 | QQ 空间说说 |
| `QZONE_PROB` | `0.012` | 每次检查发一条的概率（默认 10 分钟看一次，大概两天一条） |
| `QZONE_HOURS` | `12-22` | 只在这几个钟头之间发 |
| `QZONE_RIGHT` | `4` | 谁能看：`1` 所有人，`4` 好友，`64` 仅自己 |
| `QZONE_CHECK_MS` | `600000` | 多久看一次（毫秒） |

## 命令

| 命令 | 干什么 |
| --- | --- |
| “发条说说” / `/说说` | 让她马上发一条说说（只听主人的，私聊里发；要打开 `QZONE`） |

“主人”跟本体统一认一个：`PC_OWNER`，没填就是 `PROACTIVE_QQ` 第一个。QQ 资料（昵称、签名、头像、在线状态）由这个插件管，她自己不去改；别人让她改，她会说让主人自己改。

## 跟别的插件的关系

- 心情和作息（mood）：睡觉时段、心情从这里来，心情一变马上改状态和头像；没装就按本体的时段心情和 `SLEEP_START`~`SLEEP_END`。
- 记得你（memory）：签名是写日记时顺手写的，没装就不换签名；发说说前会避开最近 7 天聊过的人的名字。
- 她自己的生活（life）：说说的素材是她“自己找事做”（`AUTONOMY`）留下的记录，开着 ChronoLife 时只用它记下的事；
  “摸鱼中”也来自自己找事做；配图用现场照。**没装 life（或没开自己找事做），基本就没东西可发，说说会一直不发。**
- 说话的样子（speech）：唱完歌挂“听歌中”。
- 电脑上的她（pc）：自定义在线状态能写“陪你听什么”。
- 这个插件给别的插件提供“改状态、改签名、换头像”；没装它，别的插件就跳过这些。

## 注意

- **公开可见**：在线状态、签名、头像、说说别人都看得到。发之前会拦下带人名、QQ 号、“AI / 模型”这类字的内容，但还是建议先用 `QZONE_RIGHT=64`（仅自己）看看效果。
- **风控**：频繁改头像、发空间容易让 QQ 小号被风控，默认都关着，频率也压得很低，别调太高。
- **花钱**：每条说说调一次模型。
