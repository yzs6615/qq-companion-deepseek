# dsh-companion-speech（说话的样子）

让她说话更像个活人：会发表情包、会偷你的表情包、聊久了被你的口头禅带跑偏、能学某个人的说话方式，
还能用她自己的嗓子发语音、唱几句歌。

## 她多了什么

- **表情包**：偶尔在一句话后面配一张表情图。按意思挑（“无语翻白眼”“笑到打滚”），挑不到就按情绪
  （开心、无语、生气、卖萌、得意、委屈、震惊）随便挑一张。好久没发了会提醒她一句，但不会变成句句都发。
- **偷表情包**：你发来的表情包她觉得好玩，就收进自己的表情库，之后自己也拿来用（会让模型看一眼写句描述，以后能按意思挑到）。
- **学你说话**：记下你的口头禅和说话习惯，熟了偶尔学着用一两个（跟“记得你”插件提炼长期事实时一起做，不多花钱）。
- **学某个人说话**：私聊里把一段聊天记录“合并转发”给她，她列出里面有谁，你回序号或名字，
  她就慢慢被那个人的说话方式带跑偏（`MIMIC_RAMP_DAYS` 天学到位）。只学语气和习惯，不冒充那个人，不复述原话里的私事。
- **发语音**：用阿里云百炼 CosyVoice 复刻的音色，短的、带情绪的话直接说出来；可以带语气（生气、难过、委屈、害怕、惊讶、嫌弃、困），
  不写就跟着她这会儿的心情来。太长的、今天发够了的还是打字。
- **唱歌**：歌库里有提前转好的片段，她就能用自己的嗓子唱一段发过来。一首学了好几段的，提示词里列着每段开头的歌词，
  你说“唱晴天里‘刮风这天’那段”，她写 `[唱歌:晴天/刮风这天]`，按歌词挑最像的那段（两个字两个字比，听写有错字也对得上）。
- **学新歌**：让她学一首歌，她用插件里的 `sing/learn.mjs` 在后台学（B站 音轨 + 网易云带时间的歌词，一段 30 秒要 5 分钟左右，要显卡和 Seed-VC）。
  `learn.mjs start` 只把任务记成排队，本体内核每 3 秒看一眼、由内核起后台进程（DSH 起的进程一轮结束会被收掉，所以不能让她自己在后台跑）；
  `learn.mjs status 歌名` 看学到哪了。学好了就出现在会唱的歌里。B站 的签名靠“她自己的生活”插件的 `bili/bili.mjs`，没装就只能用 `--audio` 给本地音频。
- **直接跟她说**：私聊里转发聊天记录后说“学第二个人”“学小明”，她就去学（不用回序号）；说“别学了”就停掉并删掉素材；问她在学谁她知道。

## 安装

先装本体（dsh-companion-core），再装这个：

```bash
dsh plugin --profile web add github:yzs6615/dsh-companion-plugins#speech
```

用桌面版把 `web` 换成 `desktop`（先完全退出桌面版）。也可以到
[Releases](https://github.com/yzs6615/dsh-companion-plugins/releases) 下载 `dsh-companion-speech-<版本>.tgz`，
`dsh plugin --profile web add <文件路径>`。装好、卸掉后重启 DSH。卸载：`dsh plugin --profile web remove dsh-companion-speech`。

这个包依赖 `ws`（语音合成用），DSH 装插件时会自动装上。

## 设置（.env）

写在本体的 `.env` 里（默认 `$DSH_HOME/companion/.env`），改完重启 DSH。开关写 `true` / `false`，数字项别留空。

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `LEARN_STYLE` | 开 | 学你的口头禅和说话习惯（要装“记得你”插件） |
| `STEAL_STICKERS` | 开 | 收你发的表情包 |
| `STEAL_MAX` | `40` | 每种情绪最多留几张收来的，多了扔掉最早的 |
| `MIMIC` | 开 | 合并转发学某个人说话 |
| `MIMIC_RAMP_DAYS` | `14` | 多少天学到位 |
| `VOICE` | 开 | 发语音；**还要填了 `VOICE_ID` 和 `DASHSCOPE_API_KEY` 才真的开** |
| `DASHSCOPE_API_KEY` | 空 | 阿里云百炼的 API Key |
| `VOICE_ID` | 空 | 百炼 CosyVoice 复刻出来的音色 ID |
| `VOICE_MODEL` | `cosyvoice-v3.5-flash` | 合成用哪个模型 |
| `VOICE_MAX_CHARS` | `60` | 超过这么多字就打字 |
| `VOICE_MAX_DAY` | `20` | 一天最多发几条语音（`/说话` 不算） |
| `VOICE_RATE` | `1` | 语速，0.5–2 |
| `VOICE_CUT_MS` | `0` | 句尾再剪掉多少毫秒（自动去杂音之外） |
| `VOICE_EMOTION` | 开 | 语音带语气 |
| `VOICE_EMOTION_DB` | `-20` | 带语气的语音最响到多少（dBFS；平常的大约 -25） |
| `SING` | 开 | 唱歌（歌库是空的就等于没开） |
| `SING_MAX_DAY` | `6` | 一天最多唱几段（`/唱歌` 不算） |
| `STICKER_DIR` | `data/stickers` | 表情库在哪 |
| `SONG_DIR` | `data/songs` | 歌库在哪 |

**表情库**：`data/stickers/<情绪>/` 里放图（png / jpg / gif / webp），情绪是上面那七个目录名；
`data/stickers/index.json` 里给每张图一句描述（“熊猫头翻白眼：无语、看不下去”），有描述的才能按意思挑到。一张图都没有就不发表情包。

**歌库**：`data/songs/<歌名>/` 里一个 `song.json` 加几段 `NN.wav`，用插件里的 `sing/render.py` 手动转
（Demucs 分离人声 + Seed-VC 换成她的嗓子，要显卡；Seed-VC 装在哪写在 `.env` 的 `SEEDVC_HOME` 等几项，见 `sing/paths.py` 开头）。不转歌就当她还没学会唱歌。

## 命令

| 命令 | 干什么 |
| --- | --- |
| `/学说话` | 在学谁、学了几成（直接问“你在学谁”也行） |
| `/别学了` | 不学了，记下来的说话方式和原话素材都删掉（直接说“别学了”也行） |
| `/说话 一句话` | 让她把这句念出来（试音色用，不调模型） |
| `/唱歌 歌名` | 直接唱一段（不写歌名就随便唱一首） |
| `/歌单` | 会唱哪些歌 |

## 提示词里的标记

默认人设教她在回复里写这些，不会发出去，由本体抠掉后交给这个插件：

- `[表情:想表达的意思]` 或 `[表情:开心]`：配一张表情图。
- `[语音]`、`[语音:害怕]`：这句用语音说。
- `[唱歌:歌名]`、`[唱歌]`：唱一段；`[唱歌:歌名/一句歌词]` 唱那句所在的那段。
- `[收表情:情绪]`：你发来表情包时，她想收下就写这个（这个插件自己在提示词里教她）。
- `[学说话:序号或名字]`、`[别学了]`：“直接跟她说”的标记，这个插件在提示词里教她（等着选人时列出转发里的人）；标记由本体抠掉，回完那句交回这里办。

## 跟别的插件的关系

- 用“记得你”（memory）的长期事实：学你说话靠它提炼；没装就不学你的口头禅。
- 给别的插件用：电台（life）、电脑喇叭（pc）合成语音都靠这个插件；没装它们就不出声，电台发文字版。
- 学某个人说话那段，主动找你（proactive）发消息时也会带上。
- 唱歌时在线状态挂“听歌中”（要装 profile）。
- 语音的语气跟着“心情和作息”（mood）的心情；没装就不带心情语气。
- 没装这个插件：人设里的 `[表情]` `[语音]` `[唱歌]` 照样被本体抠掉，只是什么都不发。

## 注意

- **花钱、联网**：语音合成调阿里云百炼（按字数计费，从你的百炼账户扣）；收表情包时让模型看图写描述，也花一点模型额度。
- **声音只用本人同意的**：复刻音色只用你自己的、或者本人明确同意的声音；唱歌转换也一样。别拿来冒充别人。
- **歌只自己听**：歌库里的歌注意版权，别拿去公开传播。
- 学某个人说话时，转发的原话存在 `data/mimic-samples/`，`/别学了` 会删掉。转发别人的聊天记录前想想对方愿不愿意。
- 合并转发只在私聊里收；白名单里的人都能用上面这些命令。
