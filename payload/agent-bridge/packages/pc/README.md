# dsh-companion-pc（电脑上的她）

让她像“住在这台电脑里”的室友：看得见你在放什么歌、开着什么游戏、人在不在电脑前；你回来时从喇叭跟你打个招呼，
离开久了在桌面给你留张便条，还能直接在电脑上的 QQ 音乐里给你放首歌。

**只支持 Windows**（用 PowerShell、桌面、系统通知、QQ 音乐）。别的系统上装了也只会在日志里说一声，什么都不做。
除了放歌的链接，这些都只对“主人”（`PC_OWNER`，没设就是 `PROACTIVE_QQ` 第一个）。

## 她多了什么

- **电脑室友**（`PC_BUDDY`）：每隔一会儿看一眼电脑——在放的歌（网易云、QQ 音乐、酷狗、酷我、Spotify 等的窗口标题）、
  开着的游戏（认识的游戏，或者 Steam / Epic / WeGame 目录里的程序）、开机多久、键盘鼠标多久没动。
  跟主人私聊时她心里知道这些；碰上值得说的事（一首歌这周放到第 3 遍、凌晨还在打游戏、电脑连开好几天）偶尔主动说一句。
- **喇叭打招呼**（`SPEAKER`）：早上第一次开电脑、离开很久又回来时，用她的声音从电脑喇叭说一句。
  主人私聊说“用电脑喇叭跟我说句晚安”，她也会用自己的声音从喇叭说（一天最多 `SPEAKER_ASK_MAX_DAY` 句，跟打招呼分开算）；夜里、她歇着时不出声；
  只用她自己的声音，合成失败就补一句“没喊出来”，绝不拿系统语音（SAPI 这些）顶。别人、群里让她喊，她会说只听主人的。
- **桌面便条**（`NOTES`）：你离开电脑好几个小时，她在桌面留一张“<名字>的便条.txt”，你回来时右下角弹个通知。
- **桌面抽屉**（`DRAWER`）：桌面上一个“<名字>的抽屉”文件夹：写给主人的信、明信片、发给你的照片、梦、便条、她收藏的视频都放一份。
- **放歌**（`PLAY_MUSIC`）：她在回复里写 `[放歌:歌名 歌手]`，先在 QQ 音乐上搜到这首；主人在电脑前（5 分钟内动过键鼠）就直接在电脑上的 QQ 音乐里放：
  把 QQ 音乐叫到前台、在界面上搜这首、点那一行的播放，再看系统媒体信息（SMTC）确认真的在放这首；没放起来（没开、迷你模式、被挡住…）就改发链接。
  不在电脑前就发 QQ 音乐的链接。只在私聊里放；搜不了、今天放够了、群里让放，她都会补一句。
- **控制音乐**（跟着 `PLAY_MUSIC`）：主人私聊说“别放了”“接着放”“切一首”“上一首”“大声点”“小声点”，她按这台电脑的媒体键（不用管理员、不关进程；
  暂停 / 继续前先看一眼在不在放，免得按反）。别人、群里让她弄，她会说只能弄主人电脑上的。

夜里（睡觉时段、本体的 `QUIET_HOURS`，默认 23~9 点）不出声、不留条、不主动搭话。

## 安装

先装本体（dsh-companion-core），再装这个：

```bash
dsh plugin --profile web add github:yzs6615/dsh-companion-plugins#pc
```

用桌面版把 `web` 换成 `desktop`（先完全退出桌面版）。也可以到
[Releases](https://github.com/yzs6615/dsh-companion-plugins/releases) 下载 `dsh-companion-pc-<版本>.tgz`，
`dsh plugin --profile web add <文件路径>`。装好、卸掉后重启 DSH。卸载：`dsh plugin --profile web remove dsh-companion-pc`。

## 设置（.env）

写在本体的 `.env` 里（默认 `$DSH_HOME/companion/.env`），改完重启 DSH。开关写 `true` / `false`，数字项别留空。**全部默认关。**

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PC_BUDDY` | 关 | 电脑室友（喇叭、便条都靠它看键鼠，要一起开） |
| `PC_MAX_DAY` | `3` | 一天最多因为电脑上的事主动说几句 |
| `PC_SONG_PROB` | `0.12` | 新放一首歌时顺口说一句的概率 |
| `PC_CHECK_MS` | `120000` | 多久看一次电脑（毫秒） |
| `AWAY_MIN` | `120` | 键鼠多少分钟没动、又动了，算“回来了” |
| `SPEAKER` | 关 | 喇叭打招呼（要装“说话的样子”并配好语音） |
| `SPEAKER_MAX_DAY` | `3` | 一天最多自己打几次招呼 |
| `SPEAKER_ASK_MAX_DAY` | `10` | 主人让她“用喇叭说句话”的，一天最多几句 |
| `NOTES` | 关 | 桌面便条 |
| `NOTE_AFTER_MIN` | `180` | 离开多少分钟后留便条 |
| `DRAWER` | 关 | 桌面抽屉 |
| `PLAY_MUSIC` | 关 | 用 QQ 音乐放歌 |
| `PLAY_MUSIC_MAX_DAY` | `6` | 一天最多放几首 |
| `QQMUSIC_EXE` | `C:\Program Files (x86)\Tencent\QQMusic\QQMusic.exe` | QQ 音乐装在哪；找不到就只发链接 |

电脑是谁的（`PC_OWNER`）、安静时段（`QUIET_HOURS`）在本体的设置里。

## 提示词里的标记

- `[放歌:歌名 歌手]`：开着 `PLAY_MUSIC`、主人私聊说到听歌（或者深夜）时，这个插件在提示词里教她写。
- `[音乐:暂停|继续|下一首|上一首|大声|小声]`、`[喇叭:要说的话]`：主人私聊让她控制音乐、用喇叭说话时教她写；标记由本体抠掉（没装这个插件也不会原样发出去），回完那句交回这里办。
  不是主人、在群里、喇叭没开、夜里，提示词里直接告诉她为啥办不了，让她跟对方说。

## 跟别的插件的关系

- 说话的样子（speech）：喇叭说话要它的语音合成（`VOICE_ID` + `DASHSCOPE_API_KEY`）；没装或没配好就不出声。
- 她自己的生活（life）：主动搭话时带上“最近的自己”；她刷到的视频、寄的明信片、拍的照片、做的梦会放进抽屉。
- 主动找你（proactive）：写给主人的信放进抽屉（以前写的启动时也补进去）。
- QQ 上的样子（profile）：自定义在线状态能写“陪你听什么”。
- 开着 ChronoLife（life）时，电脑室友不再主动搭话（交给 ChronoLife 管）；喇叭、便条、抽屉照常，跟着它的休息时间不出声。
- 这个插件给别的插件提供“电脑现在怎么样”和“抽屉”；没装它，别的插件就跳过这些。

## 注意

- **会看你的电脑**：每隔一会儿跑一次 PowerShell，只看音乐软件和游戏的窗口标题、开机时间、键鼠空闲时间；别的窗口在 PowerShell 那一步就过滤掉，标题不进日志。
  这些只在跟主人私聊时用，群里、别的人都不知道。
- **会动你的电脑**：在桌面写文件（便条、抽屉）、弹系统通知、用喇叭放声音、打开 QQ 音乐放歌（没起来就用浏览器打开网页版）。
- **联网**：放歌时去 QQ 音乐搜歌；喇叭说话走百炼语音合成（花钱，见“说话的样子”）。
- **花钱**：主动搭话、留便条都调模型。
