# dsh-companion-life（她自己的生活）

让她不只是围着你转，而是有自己的日子：没人找她时自己去刷 B站、刷知乎微博、听歌、看番，刷到你会喜欢的就发给你；
早上醒来记得昨晚的梦；每晚回想一天，慢慢长出自己的喜好和梗；能给你录一期深夜电台、周末出去“旅行”寄明信片、
问她在干嘛时拍张“现在的她”、收下你送的礼物摆进房间。还可以打开 ChronoLife，给她一间自己的小屋。

## 她多了什么

- **自己找事做**（`AUTONOMY`，默认关）：白天每小时掷一次骰子（看心情和精神），想玩就去刷 B站、看番、刷知乎热榜、刷微博热搜、听歌，
  或者照着记得的你的喜好找点你会喜欢的（装了手机插件还可能玩会儿手机）。看到好玩的就用一两句发给 `PROACTIVE_QQ` 第一个人，不想说就不说；
  每次都在“今天干过啥”里记一笔，之后被问“刚在干嘛”对得上。你在跟她聊天时不去玩；被你打断时她会说自己刚在干嘛。
- **人设成长**（`REFLECT`）：每晚把自己找事做的经历回想一遍，总结成“最近的自己”（喜好、观点、最近在看的、学到的梗、习惯），
  反复印证的加深，太久没再印证的慢慢忘掉。`persona.md` 的核心人设不动。
- **做梦**（`DREAM`，默认关）：睡醒到中午之间，给最近 3 天聊过的人掷骰子，梦见了就在今天第一次聊天（或早安）时顺口说一句。梦是最近的事打乱了拼的。
- **深夜电台**（`RADIO`）：跟她说“开台，聊聊下雨天”“来一期开心的”“我来投稿，你帮我念”“今晚只听一分钟”，
  她就录一期两三分钟的语音节目（或一分钟版），配一张节目卡、推荐一首歌（附网易云链接）。讲的是她最近真刷到、真碰到的事；
  私聊节目能用上她记得的你的事和你那边的天气，群里的节目只用公开的。能接着上期讲、能重播。没开语音就发文字版。
- **旅行明信片**（`POSTCARD`，默认关）：隔几周的周末，她在自己的小世界里出去玩一趟（周五定去哪），周日下午给 `PROACTIVE_QQ` 第一个人寄一张明信片：
  正面是当地风景（百炼画，画不成就自己画一张），背面手写几句、贴邮票、盖邮戳。
- **现场照**（`PHOTO`，默认关）：你问她在干嘛、想看看她时，她可能拍一张“现在的她”：房间按时段和你那边的天气换，动作按她在干嘛和心情换。
- **收礼物**（跟着 `PHOTO`）：你说“送你个绿萝”，她想收就收下，画出来摆进房间，以后的现场照里能看到，还会拍一张“摆好了”。
  照片没拼成、礼物没摆好，她会补一句（“诶 照片没弄好”），不会答应了又没下文。
- **画画**（`DRAW`，默认开，要 `DASHSCOPE_API_KEY`）：主人私聊说“给我画只猫”，她用百炼通义万相画一张发回来，要半分钟到一分钟；
  一天最多 `DRAW_MAX_DAY` 张，画好的存在数据目录的 `drawings/`（开着电脑插件的桌面抽屉也放一份）。只给主人画；没 key、画够了、别人让画，她都会直接说。
- **ChronoLife 小屋**（`CHRONOLIFE`，默认关）：她有一间自己的小屋，窗台上养着植物，会整理笔记、写点东西、发呆休息，每 30 分钟过一段日子；
  聊天时她知道小屋里最近发生了什么。打开后，各插件的主动消息统一交给它管（一周最多几条、你没回就不再发）。
  详见插件里的 [chronolife/README.md](chronolife/README.md)。
- **直接跟她说**：不用记命令——“给我寄张明信片”（私聊）、“给我画只猫”（主人私聊）；开着 ChronoLife 时“帮我记着下周三考试”“那条记错了 是周四”“那个别记了”，
  主人私聊还能说“这几天别主动找我”“可以主动找我了”“歇会儿吧”改开关（跟 `/生活` 一样，开关只听主人的）。她回一句就去办，不另外发“已记录”；
  “忘掉”“更正”按你说的几个字找这个聊天里记着的那条，找不到她会说。
- **刷 B站**：`b23.tv` 短链也认（自己跟一次跳转拿到 BV 号）；`--listen` 一次最多听前 3 分钟，只用本地 Whisper 模型，没有就说没听成。
  学歌用的带时间歌词：`life/life.mjs song 歌名 歌手 --lyrics-json 文件名`（存到数据目录的 `tmp/`，`--offset 秒` 挪时间），给“说话的样子”插件的 `sing/learn.mjs --lyrics` 用。

## 安装

先装本体（dsh-companion-core），再装这个：

```bash
dsh plugin --profile web add github:yzs6615/dsh-companion-plugins#life
```

用桌面版把 `web` 换成 `desktop`（先完全退出桌面版）。也可以到
[Releases](https://github.com/yzs6615/dsh-companion-plugins/releases) 下载 `dsh-companion-life-<版本>.tgz`，
`dsh plugin --profile web add <文件路径>`。装好、卸掉后重启 DSH。卸载：`dsh plugin --profile web remove dsh-companion-life`。

要准备的（用到哪样准备哪样）：

- 电台节目卡、明信片、现场照、收礼物要 Python 和 `Pillow`。
- 刷 B站时“看画面”要 Python 的 `av`、`numpy`、`Pillow`；“听”要 `faster-whisper` 和本地模型（`.env` 的 `WHISPER_MODEL_DIR`）。
- 现场照的素材你自己准备，放在 `data/scene/`：`bg/` 里是房间（`morning` `day` `evening` `night` `rain-day` `rain-night` `snow`，jpg / png），
  `pose/` 里是透明底的动作图（`look` `happy` `sleeping` `phone` `radio` `eat` `pout` `sad` `sleepy` `lieflat` `moyu` `smug`，png / webp）。至少要有 `bg/day` 和 `pose/look`。
- ChronoLife 要 Node 带 `node:sqlite`（Node 24、新一点的 Node 22 都有）；没有的话日志里说一声，普通聊天照常。

## 设置（.env）

写在本体的 `.env` 里（默认 `$DSH_HOME/companion/.env`），改完重启 DSH。开关写 `true` / `false`，数字项别留空。
找谁分享（`PROACTIVE_QQ`，用第一个）、主人是谁（`PC_OWNER`）、睡觉时段在本体的设置里。

**自己找事做**

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `AUTONOMY` | 关 | 自己找事做（还要设 `PROACTIVE_QQ`） |
| `AUTONOMY_HOURS` | `10-23` | 只在这几个钟头之间 |
| `AUTONOMY_ROLL_PROB` | `0.35` | 每小时“想不想玩”的基础概率（再按心情、精神调） |
| `AUTONOMY_ROLL_WINDOW_MIN` | `45` | 每小时在前多少分钟里随机掷骰子 |
| `AUTONOMY_MINUTES` | `45` | 两次之间至少隔几分钟 |
| `AUTONOMY_MAX` | `8` | 一天最多几次 |
| `AUTONOMY_IDLE_MIN` | `20` | 那个人这么多分钟内找过她，这小时就不去玩 |
| `AUTONOMY_CHECK_MS` | `300000` | 多久看一次（毫秒） |
| `BILIBILI_SESSDATA` | 空 | 可选：你自己的 B站登录 Cookie，填了能读视频的 AI 字幕；不填也能刷 |

**人设成长**

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `REFLECT` | 开 | 每晚回想、人设成长（素材主要来自自己找事做，没开它就没多少可想） |
| `REFLECT_HOUR` | `22` | 几点后回想 |
| `REFLECT_CHECK_MS` | `600000` | 多久看一次（毫秒） |
| `SELF_MAX` | `30` | “最近的自己”最多几条 |
| `SELF_FORGET_DAYS` | `14` | 多少天没再印证就忘掉 |
| `RECENT_FORGET_DAYS` | `5` | “最近在看”多少天忘掉 |

**做梦**

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `DREAM` | 关 | 做梦 |
| `DREAM_PROB` | `0.5` | 每天每个人做梦的概率 |
| `DREAM_UNTIL` | `12` | 睡醒到几点之间做梦 |
| `DREAM_CHECK_MS` | `600000` | 多久看一次（毫秒） |

**深夜电台**

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `RADIO` | 开 | 深夜电台 |
| `RADIO_MAX_DAY` | `6` | 一天最多录几期（重播不算） |
| `RADIO_VOICE_SEC` | `58` | 拼成的每条语音最长几秒 |
| `RADIO_COLLECT_MS` | `6000` | 投稿连发几条时，最后一条之后等多久再开录（毫秒） |

**明信片、现场照、礼物**

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `POSTCARD` | 关 | 旅行明信片 |
| `POSTCARD_EVERY_WEEKS` | `3` | 隔几周出去一趟 |
| `POSTCARD_IMAGE_MODEL` | 同 `LETTER_IMAGE_MODEL` | 明信片正面用百炼哪个画图模型 |
| `POSTCARD_CHECK_MS` | `600000` | 多久看一次（毫秒） |
| `PHOTO` | 关 | 现场照和收礼物 |
| `PHOTO_MAX_DAY` | `5` | 一天最多发几张现场照 |
| `SCENE_DIR` | `data/scene` | 现场照素材在哪 |
| `LETTER_IMAGE_MODEL` | `wanx2.1-t2i-turbo` | 礼物用百炼哪个画图模型（跟“主动找你”的信纸共用） |
| `DASHSCOPE_API_KEY` | 空 | 阿里云百炼的 Key（画明信片、画礼物；电台的语音也用它） |
| `LETTER_FONT` | 空 | 明信片手写体字体文件；不写就依次找 Windows 自带的方正舒体、华文行楷、楷体、微软雅黑 |

**画画**

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `DRAW` | 开 | 主人私聊让她画画（要 `DASHSCOPE_API_KEY`，没有就跟主人说画不了） |
| `DRAW_MAX_DAY` | `3` | 一天最多画几张（一张一两毛钱；没画成不算） |
| `DRAW_IMAGE_MODEL` | 同 `LETTER_IMAGE_MODEL` | 用百炼哪个画图模型 |

**ChronoLife**

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `CHRONOLIFE` | 关 | 她自己的小屋 |
| `CHRONOLIFE_PROACTIVE` | 关 | 小屋里的事、刷到的东西主动跟你说 |
| `CHRONOLIFE_TIMEZONE` | 电脑的时区 | 小屋按哪个时区过日子（夜里不打扰按它算），比如 `Asia/Shanghai`；不填就用电脑的时区（取不到才用 `Asia/Shanghai`）。小屋第一次建好时记进它的数据库，之后再改这里不会变 |
| `CHRONOLIFE_TICK_MINUTES` | `30` | 多少分钟过一段日子 |

后三个只在第一次建库时当初始值，之后用 `/生活` 改的存在数据库里。

## 命令

| 命令 | 干什么 |
| --- | --- |
| `开台，聊聊下雨天` / `来一期开心的` / `我来投稿` / `今晚只听一分钟` / `上期那个话题接着讲` / `再放一遍` | 点电台（直接说就行，不用斜杠） |
| `/电台 帮助`、`/电台 列表` | 电台怎么玩、录过哪些 |
| “给我寄张明信片” / `/明信片` | 马上去一趟、寄一张（私聊，要打开 `POSTCARD`） |
| “给我画只猫” | 画一张发过来（主人私聊，要打开 `DRAW` 并配好百炼的 Key） |
| “帮我记着…”“那条记错了 是…”“那个别记了”“别主动找我了” | 开着 ChronoLife 时记住 / 更正 / 忘掉、改开关（开关只听主人的） |
| `/生活 帮助` | ChronoLife 的命令（状态、事件、记住、删除、暂停……，见 chronolife/README.md；要打开 `CHRONOLIFE`） |

## 提示词里的标记

这些都是这个插件自己在提示词里教她写的，不会发出去：

- `[电台:主题]`、`[电台:一分钟|主题]`、`[电台:续上期]`、`[电台:投稿]`：答应录一期。
- `[照片]`：拍一张现在的样子发过去。
- `[收礼物:东西名]`：收下你送的东西。
- `[日记:…]`、`[心情:…|…]`：自己找事做时记一笔、心情变了。
- `[寄明信片]`、`[画:画面描述]`、`[记住:…]`、`[忘掉:…]`、`[更正:几个字|改成啥]`、`[生活:主动 关]` 这些“直接跟她说”的标记：教她写的那几行在这个插件里，
  标记本身由本体抠掉（没装这个插件也不会原样发出去），回完那句交回这里办。

## 跟别的插件的关系

- 记得你（memory）：“找点你会喜欢的”、做梦、电台素材（日记、天气、纪念日、记得的事）、现场照看天气都靠它；没装就当不记得。
- 说话的样子（speech）：电台录语音要它的语音合成；没装或没配好语音就发文字版。
- 心情和作息（mood）：睡觉时段、心情从这里来；自己找事做时心情变了也交给它。
- 手机（phone）：装了才会“玩会儿手机”。
- QQ 上的样子（profile）：自己找事做时挂“摸鱼中”；说说的素材、配图来自这里。
- 电脑上的她（pc）：刷到的视频、明信片、照片、梦放进桌面抽屉。
- 主动找你（proactive）：早安时带上梦和“最近的自己”；信上盖的小章用现场照的动作图。自己找事做发了消息，就不再追问“人呢”。
- 开着 ChronoLife 时，别的插件的主动消息（早安晚安、回访、戳你、追问、群里插嘴、电脑室友搭话、自动写信）都停掉，交给它统一管；
  在 ChronoLife 里删掉的记忆，本体和“记得你”读记忆时也会拦下。
- 没装这个插件：本体照常聊天；`[电台]` `[照片]` `[收礼物]` 这些提示词都不会出现；`/生活` `/明信片` 当普通聊天。

## 注意

- **她会在你的电脑上跑命令、会联网**：自己找事做时，模型用插件带的脚本（`bili/bili.mjs`、`life/life.mjs`）去 B站、知乎、微博、网易云拿公开内容，
  权限跟聊天一样（本体的 `DSH_PERMISSION_MODE`）。不发评论、不点赞、不登录别人的账号；B站提示刷太快就停。
- **花钱**：自己找事做、人设成长、做梦、电台、明信片、ChronoLife 补活动细节都调模型；
  电台语音、明信片和礼物的画图走阿里云百炼，从你的百炼账户扣。默认关着的几个打开前想想额度。
- 电台推荐的歌只附链接，不下载歌曲。
- 她的“旅行”“小屋”都是她自己小世界里的事，提示词里会提醒她别说成现实里出了门。
- 数据在 `data/` 里（`self-profile.json`、`postcards/`、`scene/`、`chronolife/` 等），有聊天相关的内容，别发给别人。
