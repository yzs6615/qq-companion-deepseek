# dsh-companion-memory（记得你）

让她真的记得你：你说过的事、你几点睡几点起、你们认识多少天、你那边今天下不下雨，每天睡前还写一篇日记。

## 她多了什么

- **长期记住你的事**：隔几轮让模型把聊天里值得记住的事提炼出来（你是干嘛的、喜欢什么、最近在忙啥），聊天时自然地用上，不一条条背。
- **到点回访**：你提到的将来的事（明天考试、周五面试）记成回访，到时候主动问一句（要装“主动找你”插件并打开）。
- **记得你的作息**：按你每天几点冒头、几点没动静，算出你平时的作息；今天睡晚了、起早了她会注意到，一天只提一次。
- **对你好奇**：你还没说过的方面（干嘛的、住哪、爱好、爱吃啥、养没养猫狗、生日），聊得自然时顺口问一句，一天最多一次，不查户口。
- **纪念日**：认识第 30 / 100 / 200 / 300 / 500 / 520 / 666 / 1000 / 1314 天、周年、你的生日，她心里知道。
- **你那边的天气**：告诉她你在哪个城市，每小时看一次天气，下雨降温才提。
- **写日记**：白天每轮聊天记一行流水，晚上用她自己的口吻写当天的日记，之后聊天时带着最近几天的日记。
  跟 A 聊的事只出现在跟 A 的对话里，不会说给 B 听。
- **直接跟她说**：不用发命令——“我在杭州”“我搬去成都了”（记下你在哪，只是路过、出去玩的不算）、“我生日 5 月 20 号”（农历的不记）、
  “给我看看你的日记”。她回一句就记下 / 发过来，不另外报“记住了”；城市查不到、生日看不懂、还没写过日记，她会说。

## 安装

先装本体（dsh-companion-core），再装这个：

```bash
dsh plugin --profile web add github:yzs6615/dsh-companion-plugins#memory
```

用桌面版把 `web` 换成 `desktop`（先完全退出桌面版）。也可以到
[Releases](https://github.com/yzs6615/dsh-companion-plugins/releases) 下载 `dsh-companion-memory-<版本>.tgz`，
`dsh plugin --profile web add <文件路径>`。装好、卸掉后重启 DSH。卸载：`dsh plugin --profile web remove dsh-companion-memory`。

## 设置（.env）

写在本体的 `.env` 里（默认 `$DSH_HOME/companion/.env`），改完重启 DSH。开关写 `true` / `false`，数字项别留空。

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `FACTS` | 开 | 长期记住你的事和回访 |
| `FACTS_EVERY` | `6` | 每聊几轮提炼一次 |
| `RHYTHM` | 开 | 记得你的作息（按 `data/bridge.log` 里的消息时间算，至少要 4 天） |
| `CURIOUS` | 开 | 对你好奇 |
| `CURIOUS_PROB` | `0.3` | 每轮有多大概率提醒她问一句（一天最多一次） |
| `ANNIVERSARY` | 开 | 纪念日、生日 |
| `MEET_DATE` | 空 | 手动指定认识的日子：`QQ号:2025-05-15`，逗号隔开；不填就用第一次聊天那天 |
| `WEATHER` | 开 | 你那边的天气 |
| `WEATHER_CITY` | 空 | 默认城市；每个人也可以跟她说“我在杭州”（或发 `/城市 杭州`） |
| `JOURNAL` | 开 | 每天写日记 |
| `JOURNAL_HOUR` | `23` | 几点后写当天的日记（没写成第二天补） |
| `JOURNAL_DAYS` | `30` | 聊天时带最近几天的日记（同一段会话里没变就不重复塞） |
| `JOURNAL_CHECK_MS` | `600000` | 多久看一次该不该写日记（毫秒） |

## 命令

| 命令 | 干什么 |
| --- | --- |
| “我在杭州” / `/城市 杭州` | 告诉她你在哪（只发 `/城市` 是问她记得你在哪）；命令会顺便报一下那边天气 |
| “我生日 5 月 20 号” / `/生日 5-20` | 告诉她你的生日（`5月20`、`5.20` 也行） |
| “给我看看你的日记” / `/日记` | 看她最近一篇日记（跟你有关的那部分也会给你看） |

“直接说”的那几样是她在回复里写 `[城市:杭州]` `[生日:5-20]` `[看日记]`，本体抠掉后交给这个插件办；提炼长期事实那一次调用只读，不用工具。

## 跟别的插件的关系

这个插件给别的插件提供“记得的东西”，没装它，用到的地方都当什么都不记得：

- 主动找你（proactive）：到点回访、早安带上纪念日、每周一封信的素材（日记、记得的事）。
- 说话的样子（speech）：学你的口头禅靠这里提炼。
- 她自己的生活（life）：自己找事做时“找点你会喜欢的”、做梦、深夜电台的素材、现场照看你那边的天气。
- 心情和作息（mood）：“作息被你带偏”用的是这里算的作息；没装这个就不再挪。
- QQ 上的样子（profile）：日记写完顺手换个签名；发 QQ 空间说说时避开最近聊过的人的名字。
- 开着 ChronoLife（life）时，在 ChronoLife 里删掉的记忆，这里读长期事实和日记时也会拦下。

## 注意

- **花钱**：提炼长期事实（每 `FACTS_EVERY` 轮一次）、每天写日记都调模型。
- **联网**：天气用 Open-Meteo（免费，不要 Key），只查你告诉她的城市。
- 记下的东西都在数据目录里：`data/memory/*.facts.json`（长期事实）、`data/journal/`（日记和每天的聊天流水，流水会一直留着）。
  里面有聊天内容，别发给别人；不想让她记了就关掉对应开关并删掉这些文件。
