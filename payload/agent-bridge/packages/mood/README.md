# dsh-companion-mood（心情和作息）

让她的心情有来由、会延续：被你夸了开心一下午，被你怼了生一会儿气；凌晨陪你聊天，第二天上午就犯困；
你老熬夜，她的作息也被你带晚了；主动找你半天没理她，你再出现时她会有点小情绪。

## 她多了什么

- **心情有来由、会延续**：聊着聊着心情真变了，她在回复最后写个 `[心情:心情词|为啥]`（不会发出去），
  这个心情会持续几个小时，期间说话、在线状态、`/心情` 都跟着它；过了就回到按时段的日常心情。
  为啥心情变了只告诉惹出这事的那个聊天，别的人只看得到心情本身。
- **熬夜后犯困**：凌晨 1~5 点还在聊，第二天 7 点到中午她会犯困、懒得多说。
- **作息被带偏**（默认关）：按主人最近 7 天几点没动静，把她的睡觉时段整体挪晚（或挪早），偶尔还会抱怨一句“都怪你”。
- **被冷落的小情绪**：主动找了你、隔了好久（默认 2 小时）你才回，这一轮她会带点小情绪（阴阳一句、假装不在意），一两句就过去，不翻旧账。

心情词只有这几个：开心、兴奋、平静、无聊、懒、嘴贫、烦、有点丧、委屈、生气、困。

## 安装

先装本体（dsh-companion-core），再装这个：

```bash
dsh plugin --profile web add github:yzs6615/dsh-companion-plugins#mood
```

用桌面版把 `web` 换成 `desktop`（先完全退出桌面版）。也可以到
[Releases](https://github.com/yzs6615/dsh-companion-plugins/releases) 下载 `dsh-companion-mood-<版本>.tgz`，
`dsh plugin --profile web add <文件路径>`。装好、卸掉后重启 DSH。卸载：`dsh plugin --profile web remove dsh-companion-mood`。

## 设置（.env）

写在本体的 `.env` 里（默认 `$DSH_HOME/companion/.env`），改完重启 DSH。开关写 `true` / `false`，数字项别留空。

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `EMOTION` | 开 | 心情有来由、会延续，熬夜后犯困 |
| `SLEEP_DRIFT` | 关 | 作息被主人带偏（要装“记得你”插件，并开着它的 `RHYTHM`） |
| `SLEEP_DRIFT_MAX` | `2` | 最多被带晚几个小时（带早最多 1 小时） |
| `SULK` | 开 | 被冷落后你再开口，第一轮带点小情绪 |
| `SULK_AFTER_MIN` | `120` | 主动消息发出后隔多久（分钟）才回算“被冷落” |

睡觉时段本身（`SLEEP_START` / `SLEEP_END`）、主动找了几次没回就先不找（`IGNORE_LIMIT`）在本体的设置里。
“主人”是 `PC_OWNER`，没设就是 `PROACTIVE_QQ` 第一个。

## 提示词里的标记

- `[心情:心情词|为啥]`：这个插件在提示词末尾教她写；本体抠掉后交给这里。没装这个插件也不会原样发出去，只是不算数。

## 跟别的插件的关系

- 给别的插件用：本体（安静时段、睡觉时慢回）、主动找你（proactive，戳你、晚上不追问）、QQ 上的样子（profile，在线状态、心情头像）、
  她自己的生活（life，做梦几点醒、现场照“在睡觉”）都问这里现在是不是睡觉时段；没装就按 `SLEEP_START`~`SLEEP_END` 固定。
- 心情变了会马上让 QQ 上的样子（profile）换在线状态和头像。
- 说话的样子（speech）发语音时跟着这里的心情带语气。
- 作息被带偏要用“记得你”（memory）算的作息；没装 memory 就不再挪（停在上次算的）。
- 被冷落要有“主动找你”（proactive）或“自己找事做”（life）先主动找过你才会发生。
- 开着 ChronoLife（life）时，心情跟着 ChronoLife 走，被冷落的小情绪也不再带（“没回”这种由 ChronoLife 自己管）。
- 没装这个插件：心情只按时段变，作息固定，被冷落也没小情绪。

## 注意

- 不联网、不另外花钱（心情标记是聊天回复里顺手写的）。
