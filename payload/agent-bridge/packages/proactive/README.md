# dsh-companion-proactive（主动找你）

让她不只是等你开口：早上说声早安、晚上道个晚安、好久没联系冒个泡、你说过的事到点问一句、
无聊了戳你一下、问了你一句半天没回会追一句“人呢”，每周还给你写一封信。

## 她多了什么

- **早安晚安、冒泡**（要打开 `PROACTIVE`）：8~10 点有时说早安，22~23 点有时道晚安，你好久没动静偶尔冒个泡；
  认识 N 天、生日这种日子 9 点后说一句。话都是模型结合记得的事、今天的心情现写的，没有固定模板。一天最多 `PROACTIVE_MAX` 条。
- **到点回访**（要打开 `PROACTIVE`，并装“记得你”插件）：你说过“明天考试”，到时候她来问一句考得怎么样。
- **主动戳你**：白天你一阵子没动静，她偶尔在 QQ 里戳你一下，什么都不说，一天最多一次；无聊的时候更想戳。
- **等你回**：私聊里她问了你一句、你半天没回，偶尔追一句“人呢”“已读不回是吧”；你说了要走、或者她在睡觉就不追。
- **每周一封信**（默认关）：每周固定一天晚上，把这一周（日记、记得的事、最近聊的）写成一封信，
  信纸用阿里云百炼的通义万相按季节画，字用手写体排上去，角上盖个小章，发图片给你。画不成就用素纸，信照样寄。
  私聊跟她说“给我写封信”她就马上写一封（她回一句“行 等我写写”，写好了发过来；群里、正在写、没开写信，她会说）。

主动消息（早安、冒泡、回访……）只要一句话，调模型时只读、不用工具。

主动找的只有 `PROACTIVE_QQ` 里的人（戳你只戳第一个）；“等你回”对所有私聊都有效。
主动找了几次都没回（本体的 `IGNORE_LIMIT`，默认 2 次），她就先不找了，等你开口。

## 安装

先装本体（dsh-companion-core），再装这个：

```bash
dsh plugin --profile web add github:yzs6615/dsh-companion-plugins#proactive
```

用桌面版把 `web` 换成 `desktop`（先完全退出桌面版）。也可以到
[Releases](https://github.com/yzs6615/dsh-companion-plugins/releases) 下载 `dsh-companion-proactive-<版本>.tgz`，
`dsh plugin --profile web add <文件路径>`。装好、卸掉后重启 DSH。卸载：`dsh plugin --profile web remove dsh-companion-proactive`。

## 设置（.env）

写在本体的 `.env` 里（默认 `$DSH_HOME/companion/.env`），改完重启 DSH。开关写 `true` / `false`，数字项别留空。
先在本体的设置里写好 `PROACTIVE_QQ`（找谁）。

**早安晚安、回访**

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PROACTIVE` | 关 | 总开关：早安晚安、冒泡、纪念日、到点回访 |
| `GREETINGS` | 开 | 早安 / 晚安 / 冒泡 / 纪念日 |
| `PROACTIVE_MAX` | `2` | 每人每天最多主动说几条 |
| `PROACTIVE_IDLE_HOURS` | `8` | 你多久没说话才可能冒泡 |
| `PROACTIVE_LLM` | 开 | 主动消息让模型写；关掉就不发 |
| `FOLLOWUP` | 开 | 到点回访 |
| `FOLLOWUP_HOURS` | `9-22` | 回访只在这个时段 |
| `FOLLOWUP_IDLE_SEC` | `180` | 你刚说完话这么多秒内不回访，免得打断 |
| `FOLLOWUP_CHECK_MS` | `120000` | 多久看一次有没有该回访的（毫秒） |

**戳你、等你回**

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `POKE_SELF` | 开 | 偶尔主动戳你 |
| `POKE_SELF_PROB` | `0.04` | 每次检查戳的概率（默认 10 分钟看一次，大约一天一次） |
| `POKE_SELF_IDLE_MIN` | `90` | 你多少分钟没动静才戳 |
| `POKE_SELF_CHECK_MS` | `600000` | 多久看一次（毫秒） |
| `CHASE` | 开 | 问了没回追一句 |
| `CHASE_PROB` | `0.4` | 追的概率 |
| `CHASE_MIN` / `CHASE_MAX` | `8` / `25` | 等多少分钟才追（在这中间随机） |
| `CHASE_CHECK_MS` | `30000` | 多久看一次（毫秒） |

**每周一封信**

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `LETTER` | 关 | 每周一封信 |
| `LETTER_WEEKDAY` | `0` | 星期几写（0 = 周日） |
| `LETTER_HOUR` | `21` | 几点后写 |
| `LETTER_CHECK_MS` | `600000` | 多久看一次（毫秒） |
| `LETTER_IMAGE_MODEL` | `wanx2.1-t2i-turbo` | 信纸用百炼哪个画图模型（“她自己的生活”收礼物也读这个） |
| `DASHSCOPE_API_KEY` | 空 | 阿里云百炼的 Key；没有就用素纸 |
| `LETTER_FONT` | 空 | 手写体字体文件；不写就依次找 Windows 自带的方正舒体、华文行楷、楷体、微软雅黑 |

排字要 Python 和 `Pillow`。超过两周没跟她说过话的人，这周不写。

## 命令

| 命令 | 干什么 |
| --- | --- |
| “给我写封信” / `/信`、`/写信` | 马上给你写一封（算这周的那封；只在私聊里，要打开 `LETTER`） |

## 跟别的插件的关系

- 记得你（memory）：回访的事项、纪念日、写信的素材（日记、记得的事）都从这里来；没装就不回访、不写纪念日，信只按最近聊的写。
- 心情和作息（mood）：在睡觉时段不戳你、不追问；没装就按本体的 `SLEEP_START`~`SLEEP_END`。
- 她自己的生活（life）：早安时顺口说昨晚做的梦、带上“最近的自己”；信上的小章用现场照的动作图。没装就不带、不盖章。
- 说话的样子（speech）：在学某个人说话时，主动消息也带上那股味儿。
- 电脑上的她（pc）：开了桌面抽屉的话，写给主人的信也放一份在抽屉里。
- 开着 ChronoLife（life）时，这里的早安晚安、回访、戳你、追问、自动写信都停掉，交给 ChronoLife 统一管（免得好几个一起找你）；`/信` 照常。

## 注意

- **花钱**：每条主动消息、每封信都调一次模型；信纸每张画一次图，从你的百炼账户扣（一张大概一两毛钱）。
  每周的信先记上再写，失败了这周也不重试，免得反复扣钱。
- **联网**：画信纸连阿里云百炼。
- 主动消息会打扰人：只把愿意被找的人写进 `PROACTIVE_QQ`；夜里（23 点后）不发早安晚安。
